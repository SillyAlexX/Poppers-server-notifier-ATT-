
# Popper Discord server notifier (In development not working right now)




## Installation


```bash
  To install drag the dll file into you Mods folder
```
    
## WebHook setup

Remember to make the webhook in the channel you want to get the notifications in

```bash
  Click the ⚙️ icon on the channel you want to recive notifications -> Go to intigrations
  then webhooks -> press copy webhook URL then open ATT and paste the url in the gui
```
